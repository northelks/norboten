# A Message You Are Not Allowed to Read

Welcome to Norboten. This machine is yours: break it, fix it, reset it.

Someone left a message for everyone who logs in, in `/srv/hello/message.txt`. When you try to read
it, you are refused.

1. Make the message readable by **every** user on the system — not just you.
2. The message ends with a secret word. Put that word, alone, in a file called `reply.txt` in your
   home directory.

When you think you are done, press **`c`** on this lab's screen. It grades the machine, reboots it,
and grades it again. Stuck? Select a check and press **`h`**.
